# DD011 — Retired (moved to Contributing section)

This page has moved. The contributor progression model is governance/process content rather than a technical Design Document, so it now lives in the dedicated **Contributing** section:

→ **[Contributor Progression Model](../contributing/contributor-progression.md)**

The DD011 number is retired from the Design Document series; the content itself is unchanged.

---

## Why this moved

The Design Document series (DD001, DD002, DD003, …) specifies the simulation's technical architecture — neural circuits, body physics, validation frameworks, etc. The contributor progression model describes *how the community works together*, which is a different category. Grouping it with the technical DDs blurred that distinction.

See the [Contributing section overview](../contributing/index.md) for the full rationale and the other governance pages.
