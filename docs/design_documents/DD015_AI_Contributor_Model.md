## Why this moved

The Design Document series (DD001, DD002, DD003, …) specifies the simulation's technical architecture — neural circuits, body physics, validation frameworks, etc. The AI contributor model describes *how AI agents participate in the contribution process alongside humans*, which is a community/governance concern, not a technical artifact spec.
