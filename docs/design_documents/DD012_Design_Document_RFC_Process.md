# DD012 — Retired (moved to Contributing section)

This page has moved. The design-document RFC process is governance/process content rather than a technical Design Document, so it now lives in the dedicated **Contributing** section:

→ **[Decision Process (How Design Decisions Are Made)](../contributing/decision-process.md)**

The DD012 number is retired from the Design Document series; the content itself is unchanged.

---

## Why this moved

The Design Document series (DD001, DD002, DD003, …) specifies the simulation's technical architecture — neural circuits, body physics, validation frameworks, etc. The RFC process describes *how design decisions are made*, which is meta — DD012 was effectively a design document about how to write design documents, which created a recursive framing. Moving it out resolves that.

See the [Contributing section overview](../contributing/index.md) for the full rationale and the other governance pages.
