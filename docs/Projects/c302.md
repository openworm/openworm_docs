c302: Multi-Scale Neural Modeling Framework
===========================================

c302 is OpenWorm's neural circuit modeling framework, implementing **DD002 (Neural Circuit Architecture)** and serving as the foundation for DD005-DD009, DD014-DD015.

## What It Does

Generates NeuroML2 networks at multiple levels of biophysical detail:

| Level | Cell Type | Synapses | Use Case | DD Reference |
|-------|-----------|----------|----------|--------------|
| A | Integrate-and-Fire | Event-driven | Topology testing only | DD002 (Level A) |
| B | IAF + Activity | Event-driven | Community extensions | DD002 (Level B) |
| C | HH conductance-based | Event-driven | Default working | DD002 (Level C) |
| **C1** | **HH + graded synapses** | **Graded** | **Recommended** (Sibernetic coupling) | DD002 (Level C1) |
| D | Multicompartmental HH | Event-driven | Specialized studies | DD002 (Level D) |

**Level C1 is the default** — graded synapses match _C. elegans_ biology (no action potentials) and enable coupling with Sibernetic body physics.

## Current Status (Phase 0)

**Accepted and working:**

- 302-neuron network generation from [Cook2019](https://doi.org/10.1038/s41586-019-1352-7) connectome (DD016)
- Multi-level framework (Levels A-D) with HH channels
- Validated against Schafer lab kinematics (DD010 Tier 3)

## Roadmap

**Phase 3 (DD005):** Cell-type specialization

- Generate 128 distinct `.cell.nml` files (one per CeNGEN neuron class)
- Calibrate conductances from expression-to-electrophysiology regression
- Validate: Functional connectivity improves 20%+ vs. generic model

**Phase 4 (DD006):** Neuropeptide modulation

- Add 31,479 peptide-receptor interactions ([Ripoll-Sanchez 2023](https://doi.org/10.1016/j.neuron.2023.09.043))
- GPCR-mediated conductance modulation (seconds timescale)

**Phase 5 (DD007, DD009, DD014):** Organ circuits

- Pharyngeal network (20 neurons + 20 muscles, 3-4 Hz pumping)
- Intestinal network (20 cells with IP3R oscillator, 50s defecation)
- Egg-laying network (2 HSN + 6 VC + 16 sex muscles, two-state pattern)
